# 课表导入与调课显示修复

版本：1.5.5（versionCode 20）

　　本次更新重点修复课表导入不完整，以及调课后课程重叠显示的问题。
• 改进“形势与政策”等一学期仅安排少数几次的课程识别，按具体周次和节次导入。
• 优化选修课的导入，修正部分课程或上课安排遗漏的问题。
• 修正停课与调课的解析及显示：停课取消对应的原课程，调课按新安排替换，避免原课程与调后课程层叠显示。
• 同时修复部分小米手机在教务课表页面长按后卡住的问题，并将教务导入页顶部状态栏改为白色。

　　更新后，请重新导入之前显示不完整或调课异常的学期课表，使修正后的解析规则生效。

　　点击下方“更新下载”覆盖升级，无需卸载，原有课表和设置会保留。
