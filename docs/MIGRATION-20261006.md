# 1.0.0 功能迁移记录

## 基线与范围

基于 `v1.0.0-source`，父提交 `2bcdfce75325df9afb89d820c6743f36be834f5d`。原版恢复依据和限制见 `SOURCE-PROVENANCE.md`。原始发布 APK 保持不变；本分支是后续功能迁移，不重新定义原版发布物。

- 迁入广告辅助规则适配、插件管理、服务引导、应用排除及简化运行记录。
- 迁入公告、服务器更新下载与匿名统计，保留 Gitee 更新后备。
- 迁入用户自行填写 API 地址、密钥和模型名称的 AI 评价草稿助手。
- 保留成绩入口，隐藏快速评教。成绩使用课程导入保存的凭据重新认证，查询全部有成绩的学期；默认展开上一个已有成绩的学期。
- 未导入课程时保持原版欢迎页面，不添加学期预览卡。原版主题、课表排版和数据库结构保持不变。

## 验证

- 原始 1.0.0 APK 已通过覆盖安装复核，未卸载或清空用户数据。
- 公开目录构建的迁移 Debug 和 Release APK 均已覆盖安装到同一台手机，未清空应用数据。最终安装的是 Release 构建。
- Android 的应用、课表、领域、教务解析和数据模块合计 350 项单元测试通过，失败、错误、跳过均为 0。
- 随附分发服务器 5 项测试通过。
- Debug、Release 构建及 `lintVitalRelease` 通过。迁移 Release 包为 14,465,465 字节，SHA-256 为 `e5a70b9e446a66b10783dde893ec48d88677a5fbcb93c13655a76bee9d3ed818`。
- 手机确认未导入课程时仅显示导入入口，没有学期预览卡；成绩与学分入口保留，快速评教未显示，成绩学期可以展开和收起。
- 相同成绩认证代码此前在手机上已通过独立配置、保存凭据重新登录和全部学期获取。迁移包复验时学校连接失败，确认缓存保留和原生错误提示正常；这次缓存展示不作为实时获取成功的证据。联网后的 Release 完整获取仍需复验。
- 原版课表页面、主题资源、数据层及数据库结构与基线比较无差异；新增功能通过应用入口接入。

## 边界

成绩认证依赖系统 WebView 的多配置支持，版本不支持时提示更新；学校要求验证码或额外交互认证时不能保证全自动完成。学分页目前统计已导入课程的学分，尚未实现培养方案毕业学分进度。

广告规则引擎和导入适配已有测试，但没有逐个验证所有第三方应用，不能保证所有广告都能关闭。移入现有功能不等同于增加网络广告拦截。

公开源码经过文件及历史脱敏检查；设备数据、账号凭据、签名、本机配置和第三方原始规则整合包不在提交范围。测试只使用合成或脱敏样例。
