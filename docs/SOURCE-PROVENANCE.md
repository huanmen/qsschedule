## 恢复依据

原发布时只提交了分发清单，Android 源码未建立版本提交。本基线由本地成功编辑记录逆向恢复到原始发布完成时：还原 228 个后续文件修改记录，无未解决补丁冲突。没有把当前开发目录直接标成原版。

恢复源码通过 Release 构建、lintVitalRelease、App 的 62 项测试和课表的 76 项测试，共 138 项，无失败。与原包对比，1,253 个非签名 ZIP 条目字节一致，4 个文本资源仅换行不同；DEX 字符串表除 R8 构建标记外相同。恢复导出时补回了原包内的两份第三方 LICENSE。

该对比不是可复现构建或完整行为等价证明。重建 APK 因本机配置、构建元数据等因素不与原始 APK 字节一致；原始签名 APK 始终作为发布物保留，不用重建 APK 替换。公开源码为恢复基线，标签明确使用 `v1.0.0-source`。

## 公开审计

已检查原 Git 历史的 2,042 个对象，并检查候选源码。命中的长数字经核实为地图节点编号与页面坐标；凭据字面量命中为 JSON 字段名；测试 URL 的账号是合成值，第三方作者署名保留。

旧历史包含个人邮箱，因此公开仓库使用新的干净历史，旧私有仓库保留且不重写。只导出 Android 源码、构建脚本、数据库结构定义、必要资源和测试样例。排除：设备数据库及备份、个人网页、会话数据、手机截图、APK、签名密钥、本机路径、研究缓存和原始第三方规则整合包。

公开提交采用 GitHub 的 noreply 作者邮箱。审计只输出文件路径、类别和计数，不输出匹配到的敏感值。
