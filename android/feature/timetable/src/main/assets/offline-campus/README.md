# 高德原版地图（独立副本）

泉州师范学院（主校区）高德离线瓦片的独立副本，与"泉州师范学院地图"主文件夹互不影响。

- `amap/` —— 原始高德瓦片，z3–19 共 1300 块（标准 XYZ 结构 `{z}/{x}/{y}.png`，GCJ-02 坐标系）
- `amap-no-label/` —— 使用高德同源无标签参数重新下载的 1300 张瓦片；不经过像素涂抹，保留道路、建筑和水域；原始 `amap/` 保留作对照
- `amap-cropped/` / `amap-no-label-cropped/` —— 原图及无字瓦片来源；当前页面进一步按用户圈定的校区旋转并矩形裁切，原始文件保留
- `data/calibrated-map.js` —— 完整生成来源及旧预计算路线，保留在工作目录供核对，页面不再加载
- `data/map-runtime.js` / `data/campus-layer.js` —— 页面只加载地点和原始路段坐标，静态路网合并为少量 SVG 路径；路线由同一份路段数据按需计算
- `index.html` —— 双击即可离线浏览（Leaflet，完全离线，无需联网）
- `leaflet.js` / `leaflet.css` —— 查看器依赖
- 显示范围：按“学校区域”标注整理为标准矩形；缩放范围 z14–19

当前功能：

- z14–19 统一使用 `amap-no-label` 无标签瓦片；`amap` 原始瓦片只用于对照，不覆盖、不修改。
- 19 个地点已完成原图位置核对，3 个为区域地点，24 条旧记录保留在“待核对地点”中，不会默认参与导航。
- 道路从 z18 无标签底图的白色道路像素骨架提取，路线只沿道路图计算，不使用直线兜底。
- 已验证“俊秀图书馆 → 理工学院”约 363 米，路径包含 473 个道路点。
- 地图限制在校园及周边范围内，避免拖动到无数据区域。
- 扩展区域共 135 个地点：柯厝路 64 个、东海湾 1+1 广场 44 个、集壁小区 27 个，包含沿线店铺、公寓和三个区域入口标记。
- 其它区域没有接入页面；全量瓦片仍作为原始备份保留，便于以后重新裁切。
- “道路画笔”可以从现有白路或已保存的新路线附近起笔，逐点点击或按住鼠标绘制。新路线保存后与已有路段建立交点，参与离线寻路；画错的点可以撤销，未保存的线可取消。
- 新路线及地点编辑都保存在同一份浏览器本地数据中，导入/导出编辑时会一起处理。路线列表可删除新增路线；如果其他路线依赖它，需要先删除分支。删除地点改用页面内二次确认。
- “圈选修改区域”用于给后续地图修改下任务标记：点击地图圈出多边形，右键或双击结束，填写区域名称和修改说明后保存。区域会显示在地图上并随编辑数据导入/导出，不会自动改动底图；后续按区域范围和说明处理。
- 保存外圈后可再次圈选，在内部继续圈出更小的区域；内外区域的名称、说明和边界独立保存，删除任一区域不会连带删除其余区域。圈选时已有区域和地点图标不会拦截边界点击。
- `data/task-annotations.js` 保存已确认的 3 条新增路线和 4 个修改区域。原始手画边界保留作为参考，不直接作为操场外形。
- `data/campus-layout.js` 在校门朝下的 53.2° 布局上再逆时针旋转 90°，显示角度约为 -36.8°（等价于 323.2°），裁切为竖向矩形。右上角箭头显示实际北向，保存坐标仍为原来的 GCJ-02，经纬度和道路接入编号不变。
- `assets/athletics.svg` 是用户上传的原始操场 SVG。一操和二操按手画范围拟合各自的标准长方形，按 SVG 的 661:1218 比例等比放置，并在原位置比此前放大 12%；缩放时使用原矢量文件，不再绘制不规则四边形跑道。
- 已保存的圈选框默认隐藏；“地图显示”中的“显示圈选框”可重新显示。圈选记录、说明和编辑数据仍保留，新圈选的临时边界正常显示。
- 地图旋转使用本地 `vendor/leaflet-rotate` 0.2.8（GPL-3.0，许可随文件保留），离线运行不需要请求 CDN。
- `tiles/clean`、`tiles/original` 是逐像素验证过的无损 WebP 瓦片，保留 z14–19 全部层级；`data/tile-config.js` 控制默认图和原图对照的资源路径。PNG 来源未删除。
- 地点编辑、标签、圈选、起终点和清除路线由同一编辑器处理；道路吸附使用空间索引，路网连接图按当前路线版本缓存。标记只更新发生变化的部分，画笔预览复用已有绘图对象。

数据版权归高德所有，仅供个人学习与科研使用。

质量记录见 `qa/calibration-report.json`、`qa/acceptance.json` 和 `qa/marker-audit.html`。

重新生成区域地点：`node data/generate-regional-places.mjs`。重新裁切瓦片：`py data/crop-tiles.py`。重新生成道路和路线：`py data/build-reviewed-map.py`。验证：`node data/validate-route.mjs` 和 `py qa/verify-map.py`。

编辑功能回归：`node qa/test-road-editor.cjs`、`py qa/test-road-ui.py`。手绘道路只保证图上的明确接入关系；新线段的几何形状取决于手工沿实路绘制，不会自动校验是否可通行或自动贴合白色道路。

旋转与操场回归：`py qa/test-rotated-layout.py`，检查桌面/手机矩形裁切、SVG 比例与定位、多个缩放级别，以及旋转后的标记放置、取消和刷新恢复。圈选回归：`py qa/test-region-ui.py`、`py qa/test-region-nesting.py`。

轻量版生成：`node tools/build-runtime.mjs` 生成不含预计算路线表的运行数据；`py tools/build-lossless-tiles.py` 生成并逐像素核对 WebP；`py tools/package-map.py` 在工作目录旁生成独立目录与 ZIP，仅包含运行所需文件、当前裁切范围瓦片、许可及原图核对页面依赖。

当前 index.html 入口保持不变，原浏览器内的编辑继续可用。复制或打开另一份发布包时，浏览器本地存储不一定共用，应通过“导出编辑 / 导入编辑”转移最新编辑，发布包不会自动携带未导出的浏览器数据。

轻量化验证：`node qa/test-lightweight.cjs` 将吸附与寻路结果同旧实现对比；`py qa/test-edit-integrity.py <编辑文件路径>` 检查地点、标签、路线、圈选和单次处理事件；`py qa/benchmark-map.py <改动前index.html路径>` 生成可比较的桌面与 CPU 限速测量。

`reviewed-places.json` 保存逐点对照依据。原图对照页的红圈表示此前位置，绿圈表示原始搜索记录的位置；最终采用位置及依据见 `qa/places-review.json`。此前的 `road-network*.js`、`road-pixel-graph.js`、`ground-z*.png` 和对应生成脚本为实验产物，当前页面不加载它们。

路网来自 z18 白色道路像素，不代表现场通行许可；未添加建筑内部路线和门禁信息。路线抵达附近道路节点，页面显示地点至道路的距离。图中未连通的位置不会强行补线。
