# 泉师课程表

面向泉州师范学院学生的 Android 课程表，支持 Android 8.0 及以上。包含今日与周课表、教务导入、学期切换、校历、活动、课程提醒、桌面小部件和校园地图。

## 成绩查询（迁移分支）

在课程导入中保存教务账号后，打开“我的 → 学习情况”即可查询。每次获取使用独立、临时的 WebView 配置，从保存的账号密码重新认证，不借用课程导入的登录会话；正常过程只显示原生界面。自动获取全部有成绩的学期，默认展开上一个已有成绩的学期，其余折叠。

需要校园网或可访问教务的网络，以及支持多配置的 Android System WebView。验证码或额外交互认证不自动绕过；失败时保留本地加密缓存。快速评教入口暂时隐藏，成绩和学分入口保留。

## 第一次使用

1. 安装后先连接校园网，或开启能访问教务系统的校园 VPN。
2. 打开“我的 → 课程安排”，点击“登录教务 / 导入课程”。尚未导入时不会显示虚构的学期预览。
3. 使用自己的教务账号登录。需要自动查询成绩时，在导入页选择保存账号；账号在本机加密保存。
4. 选择需要的学期并完成导入，核对开学日期、课程时间、教学周和作息节次。
5. 回到今日或周课表查看。课表导入后可以离线查看，更新教务信息时需要网络。

## 日常功能怎么用

| 功能 | 用法与用途 |
| --- | --- |
| 今日课表 | 查看当天要上的课和活动，进入课程详情查看地点、教师及提醒。浏览其他日期后可用“回今日”返回。 |
| 周课表 | 按星期和节次查看整周安排，点击周次切换教学周，“回本周”返回当前周。 |
| 课程安排 | 管理学期、导入课程、查看校历与停调课。先选择正确学期，再检查教务变化。 |
| 添加与编辑课程 | 选择上课星期、节次及周次。同一课程可安排多个星期；遇到冲突先核对提示，再决定替换或重新选择。 |
| 课程详情与提醒 | 查看课程信息，设置提前提醒。允许系统通知后才有通知提醒；系统后台限制也可能影响提醒。 |
| 校历 | 查看节假日和校内安排，通过顶栏重新获取校历或查看原文件。校历条目需要主动加入课表，获取校历不等于应用全部安排。 |
| 活动 | 添加课程以外的安排，按日期、时间或课程节次设置。编辑时检查与已有课程的冲突。 |
| 桌面小部件 | 在手机桌面长按空白处，进入系统小部件列表，选择泉师课程表。两种样式都用于查看今日安排，可按桌面空间调整大小。 |
| 校园地图 | 在应用内查找地点和路线；定位功能需要定位权限，定位失败时仍可手动查找。 |
| 显示与外观 | 在“我的 → 显示与外观”选择主题、课程颜色、背景和文字大小。自定义背景过亮时可调整遮罩与文字颜色。 |
| 数据与存储 | 管理快照、导出和缓存。导出的课表可能包含个人信息，分享前先检查。 |

### 成绩页的阅读方式

进入“我的 → 学习情况 → 成绩”后自动读取全部学期；右上角刷新可重新获取。学期按时间排列，上一个有成绩的学期默认展开，其他学期点击标题展开或收起。

顶部显示实际读取的学期数与成绩记录数。每条课程突出成绩，下面展示学分、绩点；点击课程可展开原表的完整字段，包括平时、期中、期末、实验、口语、过程性成绩、学时、开课院系、课程号、课序号、课组、选课属性、考核方式、备注、考试性质、是否缓考和及格标志。学校空白字段显示“未提供”，不会补成零分。补考等不同考试记录保留，不擅自当作一门新课程或重复累计已修学分。旧缓存需要刷新一次才能补全新字段。

“学分”标签目前统计当前导入课表的学分，尚不代表毕业要求完成情况。快速评教暂时隐藏，待期末继续实现。

### 跳过广告插件（迁移分支）

在“我的 → 插件市场”启用跳过广告，再进入插件详情开启服务，并按引导开启系统无障碍权限。详情页也提供电池限制设置入口；系统权限开启和服务实际连接是两个状态，请以页面状态为准。

功能默认应用于支持的应用，可按需排除应用、关闭规则。内置规则保留，自行导入的规则可以管理；支持导入受限的李跳跳/GKD 规则格式，不支持的选择器不会执行。日志在独立页面显示成功或失败。

这是基于可访问节点的广告跳过，不是网络过滤。应用改版、广告控件不可访问或规则不匹配时可能失败；规则数量不等于所有广告都能处理。插件列表提供下载、更新或删除操作。

### AI 评价草稿助手（迁移分支）

在插件市场启用后，填写自己的 HTTPS API 地址、密钥和模型名称。接口需兼容 Chat Completions。选择场景，填写真实体验，设置字数范围、语气及额外要求后生成草稿。

生成后先核对事实再复制使用。字数按含标点、不含空白的字符数计算；未达到范围时会明确提示，不通过截断句子伪装达标。应用不会自动发布评价。请求直接发往你配置的模型服务，可能产生该服务的费用。

### 公告与更新（迁移分支）

“我的 → 公告”查看更新和重要通知，未读公告有标记。应用优先使用项目服务器检查更新，Gitee 为备用渠道。下载完成后由系统安装器确认安装；同签名覆盖安装通常保留数据，更新前仍建议保存课表备份。

## 常见问题

- **成绩连接失败**：确认校园网已完成认证，或校园 VPN 确实可访问教务；再点刷新。连接 Wi-Fi 本身不代表能访问教务。失败会保留上次成功成绩。
- **提示账号未保存**：回到课程导入页保存账号密码，然后重新进入学习情况。成绩查询不借用旧网页登录状态。
- **提示更新 WebView**：更新系统 Android System WebView 或设备提供的对应组件后重试。自动登录遇到学校验证码时不能绕过。
- **课程或周次不对**：检查当前学期、开学日期、上课周次和节次；检查是否有尚未确认的停调课安排。
- **提醒或小部件不更新**：检查通知、后台运行及电池限制，打开应用确认当前学期，再重新检查小部件。
- **广告没跳过**：查看无障碍服务连接、插件开关、应用排除和规则开关。不要把点击请求被接受理解成广告已关闭。
- **自建包无法覆盖安装**：签名不同会导致系统拒绝升级；不要为了安装随意卸载，以免丢失本地数据。

## 构建

安装 JDK 17 和 Android SDK 34，在 `android/` 目录执行：

```shell
./gradlew :app:testReleaseUnitTest :feature:timetable:testReleaseUnitTest :app:assembleRelease
```

Windows 使用 `gradlew.bat`。通过 `ANDROID_HOME` 或本地 `local.properties` 配置 SDK；不要提交本机路径。地图定位 SDK 的 Key 使用 `AMAP_LOCATION_KEY` 环境变量或本地 Gradle 属性配置，仓库不提供 Key。

此基线的 Release 构建沿用当时本地验收签名配置。新机器会生成不同签名，不能用自行构建的 APK 覆盖官方签名版本；发布签名文件不在仓库中。
