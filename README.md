# 泉师课程表

面向泉州师范学院学生的非官方 Android 课程表，支持 Android 8.0 及以上。围绕课程导入、日常提醒和校园信息查询设计，按需安装插件。

[下载与插件列表](https://huanmen.com.cn/qsschedule/site/) · [GitHub](https://github.com/huanmen/qsschedule) · [Gitee](https://gitee.com/huandyu/qsschedule)

当前公开版本：**1.5.3（versionCode 18）**。软件仍在持续完善，欢迎通过两侧仓库的 Issues 反馈问题和建议。

## 主要功能

- **今日与周课表**：查看当天课程、按教学周浏览课表，管理多个学期，添加和编辑自定义课程。导入后可离线查看。
- **教务信息查询**：使用自己的教务账号导入课程，查询成绩、学分、停课与调课和作业。成绩支持本地缓存；选修学分合并跨学科选修与艺术类校选课，并提供选修要求解读。
- **校历与日历**：获取学校校历，自动导入节假日、调休、校运会和寒暑假起止节点到课表与日历，其他节点进入日历。手动活动只在日历显示，不占用课程格子。
- **活动安排**：支持标题、内容、地点、全天事件、时间点与区间，可按教学周、星期、每天、每月、自定义间隔及多个时间点重复；提供预览日历、提醒排除日期、背景色、日期与周次筛选、已过期安排批量删除。
- **分类提醒**：课程、作业、活动分别管理提醒，支持通知栏和屏幕弹窗。课程提醒可选择节假日是否提醒；插件需要额外提醒时提供对应设置。
- **桌面小组件**：在手机桌面查看当天课程和安排。
- **校园地图**：内置离线校园地图与路线导航，方便查找校园地点。
- **显示与数据管理**：主题、课程颜色、背景、文字大小，以及课表快照、导出和缓存管理。
- **公告与更新**：未读公告标记、服务器检查更新、下载进度及已下载/总大小展示，支持暂停、继续、取消和后台下载。普通公告不带更新按钮，更新公告关联对应版本。

## 按需安装插件

在“我的 → 插件市场”下载需要的功能。当前上架两个插件：

### 广告辅助

自动跳过其他软件中已适配的广告，需要用户主动开启无障碍服务。支持应用排除、规则管理、运行日志和后台设置引导；服务正常连接时响应前台应用及界面变化，持续检测可处理的广告。

这不是网络广告过滤器，也不保证关闭所有广告。应用改版、广告控件不可访问、规则不匹配或系统限制后台运行时可能失效。请以广告实际关闭结果为准。

### 赛事与考证

查询赛事与证书资料、报名及比赛时间节点、来源与核对日期，关注需要的项目，并按公开渠道的更新能力区分可订阅与暂无订阅。资料从服务器下载，仍在持续整理和优化，不能代替主办方发布的正式信息。

插件市场还支持兼容的第三方 HTTPS 规则目录。规则与资料更新不等于执行代码更新；新增原生能力仍需要升级 App。接入方式及兼容范围见 [插件接入说明](docs/PLUGIN-SDK.md)。

## 第一次使用

1. 从[下载页面](https://huanmen.com.cn/qsschedule/site/)获取安装包。
2. 连接能正常访问学校教务系统的网络，在“我的 → 课程安排”登录教务并导入所需学期。
3. 核对开学日期、教学周、节次和课程地点。需要自动查询时，可选择在本机加密保存教务账号。
4. 按需开启通知权限、设置课程和活动提醒，检查系统后台运行及省电限制。
5. 在插件市场安装自己需要的功能，不需要的插件可以不安装。

实时获取教务信息需要可访问教务系统的网络，不绕过验证码或额外交互认证。已有成绩缓存可离线查看，刷新需要网络。停调课、作业和课程提醒以当前学期为对象，不随浏览其他学期的课表切换。

## 下载、更新与统计

应用优先从项目服务器检查更新和下载，Gitee 保留兼容旧版本的更新渠道。安装包通过 HTTPS 分发并校验 SHA-256，安装仍需系统安装器确认。部分资料可以独立更新，新增原生功能或更新能力变化时需要升级安装包。

覆盖升级应使用相同包名和签名，更新前建议备份课表。自行构建的不同签名 APK 不能直接覆盖官方安装版本。

[公开页面](https://huanmen.com.cn/qsschedule/site/)展示安装包下载记录、已上架插件及插件下载统计。请求可能包含重复下载和测试，客户端下载完成回报也有覆盖范围限制，**下载量不等于活跃用户数**。

维护者可通过独立登录后台添加插件、编辑规则与赛事资料、保存草稿、发布与下架、恢复历史版本和查看统计。详见 [插件后台管理](docs/PLUGIN-ADMIN.md)。密码与部署凭据不应提交到仓库。

## 常见问题

- **无法连接教务**：检查当前网络是否确实可访问学校教务系统；连接 Wi-Fi 本身不代表已完成认证。查询失败时可先查看已有缓存。
- **课程、周次或停调课不对**：核对学期、开学日期、教学周与节次，再刷新教务信息；反馈时附上脱敏后的问题描述。
- **提醒、小组件或广告辅助不工作**：检查对应开关、通知权限、无障碍服务连接状态，以及系统省电和自启动设置。
- **无法覆盖安装**：先检查签名和版本，不要为了安装随意卸载，以免丢失本地数据。

## 构建与开发

客户端主要使用 Kotlin、Jetpack Compose 和 Android 原生组件，服务端工具使用 Python。安装 JDK 17 和 Android SDK 34，在 `android/` 目录执行：

```shell
./gradlew :app:testReleaseUnitTest :feature:timetable:testReleaseUnitTest :app:assembleRelease
```

Windows 使用 `gradlew.bat`。通过 `ANDROID_HOME` 或本地 `local.properties` 配置 SDK，不要提交本机路径、密钥或签名文件。第三方 SDK 配置及发布签名由构建者自行提供和保管。安装包名称统一采用“泉师课程表”前缀。

历史源码来源与核验范围见 [源码来源说明](docs/SOURCE-PROVENANCE.md)，旧标签不代表当前发布版本。

## 隐私与许可

请勿在 Issues、日志或导出的课表中公开账号、密码、Cookie、个人成绩和其他敏感信息。教务账号在用户选择保存后于本机加密存储；公开源码不包含发布签名、部署密码和个人教务数据。详情见 [隐私说明](PRIVACY.md)。

本项目为非官方工具，与学校及相关服务提供方不存在官方隶属关系。教务信息以学校系统为准，赛事与考证信息以注明的公开来源为准。
